## 📚 Topics Covered

### 1. Strings & Tuples

📓 **Notebook:** [Strings & Tuples](Strings_%26_Tuples.ipynb)

| Concept | Topics Practiced |
|---|---|
| 🔤 Strings | Concatenation and string operations |
| ✂️ Indexing & Slicing | Accessing characters, extracting parts, reversing strings |
| 🛠️ String Methods | `upper()`, `lower()`, `capitalize()`, `count()`, `replace()` |
| 📦 Tuples | Creation, concatenation, repetition, indexing, and slicing |

**Example:**
~~~python
text = "Python Programming"

print(text.upper())
print(text[0:6])
print(text[::-1])
~~~

### 2. Data Structures & Conditional Statements

📓 **Notebook:** [Data Structures](Data_Structures_.ipynb)

| Concept | Topics Practiced |
|---|---|
| 📋 Lists | Creation, indexing, slicing, append, insert, remove, pop, extend, sorting |
| 📖 Dictionaries | Key-value pairs, accessing, adding, updating, `keys()`, `values()`, `items()` |
| 🔢 Sets | Unique elements, union, and intersection |
| ⚙️ Conditional Statements | `if`, `elif`, `else` and comparison-based decisions |

**Example:**
~~~python
numbers = [10, 20, 30, 40]

numbers.append(50)
numbers.sort(reverse=True)

print(numbers)
~~~
