## 💻 Code Preview

**String operations**

```python
text = "Python Programming"

print(text.upper())
print(text.lower())
print(text[::-1])
print(text.count("m"))
print(text.replace("Python", "Learning"))
```

**Tuple operations**

```python
first = (1, 2, 3)
second = (4, 5)

print(first + second)  # Concatenation
print(first * 2)       # Repetition
print(first[0])        # Indexing
print(first[1:])       # Slicing
```

